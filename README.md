# SevenSins - Trésors Sacrés (Paper 1.21.4, Java 21)

Compilation : `mvn package` -> le .jar est dans target/SevenSins-1.0.0.jar, à mettre dans /plugins.

Commandes (permission sevensins.admin, op par défaut) :
- /sin give <lostvayne|chastiefol|gideon|rhitta|herritt|courechouse|aldan> [joueur]
- /sin giveall [joueur]
- /sin list

Textures : chaque arme a un CustomModelData (1001 à 1007, dans l'ordre ci-dessus).
Crée un resource pack avec un modèle par CMD pour afficher tes images.
